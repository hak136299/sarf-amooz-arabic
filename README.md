# صرف‌آموز عربی

نسخه آغازین برنامه Flutter برای آموزش صرف افعال عربی پایه‌های هفتم تا نهم.

## اجرا

```bash
flutter pub get
flutter run
```

## ساخت APK

در GitHub مخزن بسازید، این فایل‌ها را در ریشه مخزن قرار دهید و push کنید. از بخش Actions می‌توانید workflow با نام Build Android APK را اجرا کنید. فایل APK در Artifact با نام Sarf-Amooz-APK قرار می‌گیرد.

## نکته آموزشی

این نسخه نمونه آموزشی با فعل «كتب» و فرهنگ محدود چند فعل است. صرف فعل‌های مزید، معتل، مهموز و قواعد جزئی اعراب هنوز پیاده‌سازی نشده‌اند. نتایج کارنامه نیز در این نسخه فقط تا زمان بسته‌شدن برنامه در حافظه نگهداری می‌شوند.
